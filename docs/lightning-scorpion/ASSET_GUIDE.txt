LIGHTNING SCORPION ASSETS

Unzip this package into the Brainrot Defense project root (the folder containing package.json).
CharacterTypeId: lightning-scorpion. Rank tiers: 1-3 V1, 4-7 V2, 8-10 V3. Use mergeRank, not XP level.
Spritesheets are 1024x256 RGBA PNGs, 4 horizontal 256x256 frames. Idle/walk repeat; attack/hurt play once.
Unit origin: (0.5, 0.875); effect origin: (0.5, 0.5). Suggested displayed width: 112px, adjusted for battlefield tile size.
Separate frames are included under each frames/ directory. Three static unit images and three icons are also included.
The package contains asset files and an integration prompt. It does not modify game source code.
Visual QA should include actual in-game rank tiers, transition timing, and mobile scaling.
