## Integration requirements

1. Map each skin to a matching existing component before changing anything. Apply only where the aspect ratio and visual hierarchy fit. Leave unmatched skins unused and report them; do not create new screens or controls to consume the pack.
2. Preserve layout, component dimensions where possible, responsive breakpoints, all gameplay and navigation behavior, text content, values, and save data.
3. Keep text as live HTML. Do not bake labels into images, replace accessible names, remove focus rings, reduce touch targets, or weaken keyboard and screen-reader behavior.
4. Preserve readable contrast. Inspect panels behind long/localized text and at narrow mobile sizes. Avoid stretching ornate borders; use `border-image`/nine-slice or CSS background sizing only when the asset supports it, and fall back to the current styling when a skin would distort or reduce readability.
5. Coordinate with the newly integrated HUD icons without duplicating decorative borders or making controls visually noisy. Respect the existing theme and reduced-motion behavior.
6. Preserve all character/enemy graphics, effects, Chaos Arena terrain and portal, and existing HUD icon work. Update production asset verification and service-worker/precache coverage following project conventions.
